# 道の駅インスタ投稿用 画像エディタ (Michieki Instagram Editor)

正方形の写真から、Instagram投稿用の**「サムネイル画像」**および**「本投稿（カルーセル用）画像」**を一括生成し、ZIP形式でまとめてダウンロードできるWebアプリケーションです。

サーバー不要（100%クライアントサイド実行）で動作するため、**GitHub Pages** にそのままデプロイして安全・高速・完全無料で利用できます。

---

## 🌟 主な機能

1. **ドラッグ＆ドロップ対応の複数画像アップロード**
   - 複数枚の写真をまとめて選択・ドロップ可能。
   - 1:1 正方形以外の写真が混ざっていた場合、⚠️ 警告バッジが表示され、ページ上のトリミングツールで直感的に正方形に切り抜けます。

2. **「サムネイル」＆「本投稿」の自動加工**
   - **サムネイル画像（1.4x キャンバス）**:
     - 元画像（$x \times x$）を左右中央に配置、上部余白 $0.1x$。
     - 下部 $0.3x$ の情報エリアに「道の駅巡り(近畿)#(番号)」「（道の駅名）」「(都道府県) (市町村)」を3行中央揃えで配置。
     - 文字フォント: 「ふい字P 2.9」（文字色: 真っ黒、太字 / Bold）。
     - フォントサイズ: メイン文字 $0.07x$ / サブ文字 $0.056x$。
   - **本投稿画像（1.2x キャンバス）**:
     - 元画像（$x \times x$）を中央に配置（上下左右余白 $0.1x$）。
   - **背景・余白カラー**:
     - 初期値: `RGB(230, 255, 230)`（爽やかなミントグリーン）。
     - カラーピッカーおよび RGB 数値入力で自由に変更可能。

3. **道の駅名のインクリメンタル予測補完 ＆ 新駅の登録・管理**
   - 全国の道の駅データベースを内蔵（9地方分類: 北海道、東北、関東、北陸、中部、近畿、中国、四国、九州・沖縄）。駅名を入力し始めると候補が即座に表示され、クリック1つで「都道府県」「市町村」「地域」が自動入力されます。
   - 未登録の新しい道の駅は「この情報で登録」ボタンを押すことでブラウザ（`localStorage`）に保存され、次回から補完候補として表示されます（管理モーダルから確認・個別削除も可能）。

4. **一括ZIPダウンロード ＆ 同名ファイル重複防止**
   - 「サムネイルも含めた全画像の一括zipダウンロード」ボタン1つで、全画像を `(元ファイル名)_edited.png` としてZIP化して即時保存。
   - 同名ファイルが複数ある場合も `_1_edited.png`, `_2_edited.png` のように自動連番が付与され、上書きを防止します。

## 🔤 フォントファイル「ふい字P」の設定方法

### 方法 A: リポジトリ内に配置する（推奨・完全自動読み込み）
手元の `HuiFontP29.lzh` を解凍して取り出した **`HuiFontP29.ttf`** を、本プロジェクトの **`fonts/` フォルダ内**に配置してください。
配置するだけで、アクセス時に自動的に「ふい字P」が適用されます。

### 方法 B: 画面上からその場で選択する
ヘッダー右上の **「フォント選択」** ボタンをクリックし、手元の `HuiFontP29.ttf` を選択すると、ブラウザ上で即座にフォントが適用されます。

## 🚀 ローカルでの動作確認方法

ターミナルで以下のコマンドを実行してローカルサーバーを起動します：

```bash
uv run python -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセスしてください。

## 🌐 GitHub Pages への公開方法

1. このフォルダ内のファイルを GitHub リポジトリ（例: `michieki_edit`）にコミット＆プッシュします。
2. GitHub リポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** の Source で `Deploy from a branch` を選び、`main`（または `master`）ブランチの `/ (root)` を選択して **Save** をクリックします。
4. 数分で公開 URL（`https://<ユーザー名>.github.io/michieki_edit/`）が発行され、PC・スマートフォン問わずどこからでも利用可能になります。
